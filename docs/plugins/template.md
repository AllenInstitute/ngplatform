# Plugin page template

Copy this page to `docs/plugins/<your-plugin>.md`, add it to the `nav` in
`mkdocs.yml`, and fill it in. Keep it for users; the developer details
belong in the plugin's own `README.md`.

```markdown
# Plugin name

![What it looks like in use](../images/plugins/your-plugin.png)

**Kind:** tool or data type · on or off by default · where it lives (a panel in
the Tools dock, a switch, a command) · [Source and developer README](link to the folder)

One paragraph: what it is for, and what it works on.

## Using it

The steps, the controls, and what they do.

## Notes from users

*Add your tips, workflows and problems here (edit this page on GitHub).*
```

Figures go in `docs/images/plugins/`, as PNG, about 1400 px wide. The
plugin's `README.md` should show the same figure at its top.
